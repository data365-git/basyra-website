## THE CORE LESSON (took many rounds to learn)
The goal is **RICH BUT CALM** — the **mentor section is the quality bar**: photorealistic, warm, premium, full of detective soul, AND calm with clear hierarchy (eye goes face → quote → stats, no jumping).

Two failure modes we keep hitting — avoid both:
- ❌ **Too dense** (old Dastur tarkibi): rich cards + lamp + globe + keys + fingerprint + stacked papers + repeated stamps = everything shouts, eye jumps. Caused by PROP CLUTTER and adding instructions.
- ❌ **Too simple** (flat Dastur tarkibi): stripped all soul, generic template line-icons = lifeless.

**The resolution:** Richness lives *inside* each element (texture, warm light, characterful icon). Calm lives in the *spacing and the empty background*. Keep the soul, remove the surrounding props, give it room.

## PROMPT-WRITING DISCIPLINE (how I must write each prompt)
1. **Short, not long.** Long prompts = cluttered images. Describe MOOD richly, but specify FEW elements.
2. **Lead with REMOVE, not ADD.** Adding instructions adds clutter — the opposite of what we want.
3. One icon + title + one line per card. No mini-scenes inside elements.
4. Always paste the PROMPT HEADER above, then only the section-specific content + the 1–2 targeted changes.
